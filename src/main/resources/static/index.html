File format requirements for the STOR Course Scheduler

1. Preference File (Required)

The preference file contains professor teaching time preferences with willingness scores.

Required Columns:

  • Professor Name - Full name of the professor
  • ID - Professor's unique identifier (usually initials)
  • Back to Back? - 1 if professor prefers back-to-back classes, 0 otherwise
  • Time slot columns (e.g., MWF 8:00-8:50, TTH 9:30-10:45) - Willingness scores from 1-10
  • Notes - Optional notes or special requests

Willingness Scores:

  • 1-3: Low preference
  • 4-6: Moderate preference
  • 7-9: High preference
  • 10: Very high preference
  • Empty/Blank: Not available for that time slot

Example:

Professor Name,ID,Back to Back?,MWF 8:00-8:50,MWF 9:05-9:55,TTH 8:00-9:15,Notes
John Smith,JS,1,10,8,5,Prefers morning classes
Jane Doe,JD,0,,,10,Only available TTH

2. Course Data File (Required)

The course data file contains information about courses, enrollment, and instructor assignments.

Required Columns:

  • ClassNum - Course number/identifier (e.g., 120, 435, FYL20)
  • TotalStudents - Total number of students enrolled (can be empty)
  • StudentsPerSection - Maximum students per section (defaults to 50 if empty)
  • Recitations - Number of recitation sections (can be empty)
  • Instructors - Multiple columns for instructor IDs (e.g., Instructor1, Instructor2, etc.)

Instructor Values:

  • Professor ID (e.g., JMcL, VP) - Assigned professor
  • NH - No assignment needed
  • DS - Department staff
  • NOASSIGNMENT - No assignment
  • GS - Graduate student

Example:

ClassNum,TotalStudents,StudentsPerSection,Recitations,Instructors,,,
120,300,100,1,JMcL,VP,VP,
435,400,100,,SBa,SBh,SBh,MOC
155,300,100,,Sba,MG,MG,

3. Hardset File (Optional)

The hardset file specifies courses that must be taught at specific times, rooms, and by specific faculty.

Required Columns:

  • name - Course number/identifier
  • faculty - Faculty ID (must match IDs in preference file)
  • room - Room name (e.g., Hanes120, Hanes107, H125, Gardner, GradStudentRoom)
  • time - Time slot identifier (e.g., MWF800850, TTH800915)

Time Slot Format:

  • MWF = Monday, Wednesday, Friday
  • TTH = Tuesday, Thursday
  • Format: MWF800850 = MWF 8:00-8:50
  • Format: TTH800915 = TTH 8:00-9:15

Example:

name,faculty,room,time
320,ML,Hanes120,TTH800915
435,SBh,Hanes107,MWF11151205

Note: If not provided, the system will use default hardsets from the project directory, or skip hardset constraints if no file exists.

4. Conflict File (Optional)

The conflict file specifies pairs of courses that cannot be scheduled at the same time.

Required Columns:

  • Course1 - First course number
  • Course2 - Second course number (conflicts with Course1)

Example:

Course1,Course2
320,120
435,155

Note: If not provided, the system will use default conflicts from the project directory, or skip conflict constraints if no file exists.

General Notes

  • All files should be in CSV format (comma-separated values)
  • Files should have a header row with column names
  • Empty cells are allowed and will be handled appropriately
  • The Preference and Course Data files are required
  • The Hardset and Conflict files are optional
  • If optional files are not provided, the system will use defaults or skip those constraints
